Installation

Installationsguide

Windows, macOS och Linux. Gör det här innan första lektionen.

Hej! Här är allt du behöver installera inför kursen, uppdelat per operativsystem. Leta upp ditt eget system, följ stegen uppifrån och ned, och hoppa över resten. Räkna med 30–45 minuter, varav det mesta är att vänta på nedladdningar.

Det är helt normalt att något strular. Om du kör fast: ta en skärmdump på felmeddelandet och skicka den via meddelanden i Omniway. Hellre det än att du sitter en kväll och svär åt en PATH-variabel.

Innan du börjar – tre konton

Programmen är gratis att installera, men några av dem kräver att du loggar in. Skapa kontona först så går resten smidigare.

  • GitHub-konto (gratis). Hemmet för din kod och inloggningen till Copilot. github.com/signup
  • Claude-konto med Pro-abonnemang. Claude Code kräver ett betalt konto (Pro räcker) eller ett API-konto i Claude Console. Gratiskontot fungerar inte i Claude Code. claude.ai
  • GitHub Copilot. Copilot Free räcker för att komma igång. Som studerande kan du även ansöka om GitHub Education, som kan ge dig Copilot Pro utan kostnad: education.github.com

Ett ord om terminalkommandon

Flera steg nedan går ut på att klistra in ett kommando i terminalen. Kopiera hela raden, klistra in, tryck Enter. Rader som börjar med # är kommentarer – dem behöver du inte köra.

Allmänt tips: kör aldrig ett installationsskript från internet om du inte vet vem som står bakom det. Alla skript i den här guiden kommer direkt från respektive tillverkare.

Windows 10 / 11

Vi använder winget, Windows inbyggda pakethanterare, för det mesta. Öppna Windows Terminal eller PowerShell (sök på ”Terminal” i Start-menyn). Du behöver inte köra som administratör om inget annat sägs.

Krav: Windows 10 (version 1809 eller senare) eller Windows 11.

Steg 1 – Git

Installera Git först. Claude Code på Windows använder Git Bash i bakgrunden, så ordningen spelar roll.

Föredrar du klick? Ladda ner installationsprogrammet från git-scm.com/downloads och kör med standardinställningarna.

Steg 2 – VS Code och GitHub Copilot

  1. Starta VS Code.
  2. Öppna Extensions (Ctrl+Shift+X), sök på ”GitHub Copilot” och installera.
  3. Klicka på kontoikonen nere till vänster och logga in med ditt GitHub-konto.

Steg 3 – Claude Code

Stäng terminalen och öppna en ny. Skriv sedan claude och följ inloggningen i webbläsaren med ditt Claude-konto.

Använder du hellre winget: winget install Anthropic.ClaudeCode. Kör du vanliga cmd i stället för PowerShell finns ett cmd-kommando på docs.claude.com.

Steg 4 – OpenCode

Välj ett av alternativen. Har du redan Node.js installerat är npm enklast.

Har du varken Node.js, Scoop eller Chocolatey? Installera Node.js med: winget install OpenJS.NodeJS.LTS – öppna en ny terminal och kör alternativ A.

Valfritt: WSL

Om du redan jobbar i WSL (Linux inuti Windows) kan du installera allt där i stället, enligt Linux-avsnittet. Det är inget krav – vanliga Windows fungerar utmärkt för kursen.

macOS

På Mac använder vi Homebrew, den pakethanterare som nästan alla utvecklare på Mac kör. Öppna Terminal (Cmd+Mellanslag, skriv ”Terminal”).

Steg 1 – Homebrew

Har du redan Homebrew? Kör brew —version. Får du ett versionsnummer kan du hoppa till steg 2.

Installationen ber om ditt Mac-lösenord (inga tecken syns när du skriver – det är meningen). Läs det installationen skriver i slutet: på Apple Silicon-Macar visar den två rader du ska köra för att lägga till brew i din PATH. Kör dem.

Steg 2 – Git

macOS kan fråga om att installera ”Command Line Developer Tools”. Säg ja – det är helt i sin ordning.

Steg 3 – VS Code och GitHub Copilot

  1. Starta VS Code från Program-mappen.
  2. Öppna Extensions (Cmd+Shift+X), sök på ”GitHub Copilot” och installera.
  3. Logga in med ditt GitHub-konto via kontoikonen nere till vänster.
  4. Tryck Cmd+Shift+P, skriv ”Shell Command: Install ‘code’ command in PATH” och kör. Då kan du öppna mappar med code . i terminalen.

Steg 4 – Claude Code

Öppna ett nytt terminalfönster, skriv claude och logga in med ditt Claude-konto.

Alternativ via Homebrew: brew install —cask claude-code. Notera att brew-versionen inte uppdaterar sig själv – kör brew upgrade då och då.

Alternativ via Homebrew: brew install anomalyco/tap/opencode

Beroende på vilket språk du kör

Välj det som matchar det du faktiskt kommer koda i under kursen. Ingen anledning att installera alla tre.

Python

I VS Code: installera tillägget ”Python” från Microsoft. Vill du ha en renodlad Python-IDE finns PyCharm på jetbrains.com/pycharm.

C# / .NET

Installera senaste LTS-versionen av .NET SDK från dotnet.microsoft.com/download – där finns färdiga installationsprogram för alla tre systemen. I VS Code: tillägget ”C# Dev Kit”. Alternativ IDE: Visual Studio (endast Windows) eller Rider (alla system, jetbrains.com/rider).

Java

I VS Code: ”Extension Pack for Java”. Alternativ IDE: IntelliJ IDEA (Community-versionen är gratis, jetbrains.com/idea).

När något strular

”command not found” / ”känns inte igen som ett kommando”

Nio gånger av tio: terminalen startades innan installationen. Stäng alla terminalfönster och öppna ett nytt. Hjälper inte det, starta om datorn – tråkigt, men effektivt.

Windows: ”running scripts is disabled on this system”

PowerShell blockerar skript som standard. Kör detta en gång och försök igen:

Claude Code säger att kontot saknar åtkomst

Du är troligen inloggad med ett gratiskonto. Kontrollera att du har Pro (eller ett API-konto) och kör /login inne i Claude Code för att logga in igen.

Copilot svarar inte i VS Code

Kolla att du är inloggad med rätt GitHub-konto (kontoikonen nere till vänster) och att Copilot är aktiverat på github.com/settings/copilot.

npm: ”permission denied” (Mac/Linux)

Kör inte npm med sudo. Använd curl-skriptet för OpenCode i stället – det installerar i din hemkatalog och behöver inga extra rättigheter.
